# :lucide-timer: Freedom on Windows

!!! abstract "Role"

    schedule focused time by blocking selected distractions.

Freedom can help protect a recurring work, study, rest, or family block. Use it alongside—not instead of—clear notification settings and a Windows account and focus settings that is not easy to override.

[Visit Freedom :lucide-external-link:](https://freedom.to){ .md-button .md-button--primary target="_blank" rel="noopener" }

| | |

| :lucide-refresh-cw: **Sync** | One session can block on all your devices. |

## :lucide-settings: How it works

- Blocks apps, websites, or the whole internet, with no limit on how many you add.
- Offers preset blocklists and unlimited custom ones.
- Can block everything except sites you allow.
- Starts sessions on advance or recurring schedules.
- Can play ambient sound or focus music during a session.
- Has no streaks, points or leaderboards.

## :lucide-triangle-alert: Good to know

- Locked Mode, unlimited sessions and sync need Premium.
- The site lists a 7-day free trial in one place and a 30-day trial in a customer quote. Confirm the current terms before you sign up.
- Its productivity statistics come from the company, so treat them as marketing.

## :lucide-list-checks: Suggested setup

1. Start with the two or three apps or sites that most often interrupt you.
2. Create one short recurring block at a realistic time.
3. Test that your essential calls, maps, and work tools still function as intended.
4. Expand only after the first block becomes routine.

Use the same short list of distractions across your devices when you want a consistent focus routine.
