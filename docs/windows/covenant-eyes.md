# Covenant Eyes on Windows

**Role:** add accountability and, where available, filtering support.

Covenant Eyes is a relationship-centered option: decide in advance who receives reports or helps with the setup, and make sure everyone understands the boundaries and privacy expectations.

## Suggested setup

1. Choose an accountability partner who can respond constructively.
2. Read the current compatibility and privacy information together.
3. Install and test the service before depending on it.
4. Set a regular check-in that focuses on progress, not shame.

For mobile coverage, review the iPhone, Android, or iPad section that matches your household.
