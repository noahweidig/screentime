# :lucide-book-a: Glossary

Terms used across this wiki. Hover a dotted term on any page for a short definition.

## :lucide-sliders-horizontal: Built-in controls

Screen Time
:   Apple's built-in tool for app limits, Downtime and content restrictions on iPhone, iPad and Mac.

Digital Wellbeing
:   Google's built-in Android tool for app timers, Focus mode and Bedtime mode.

Downtime
:   A Screen Time schedule that allows only the apps you choose and phone calls.

App Limits
:   Screen Time daily limits for app categories or individual apps.

Family Sharing
:   Apple's feature for sharing purchases and parental controls within a household.

Family Link
:   Google's app for supervising a child's Android device.

## :lucide-ban: Blocking

Blocklist
:   Sites or apps that are blocked. Everything else is allowed.

Allowlist
:   The only sites or apps permitted. Everything else is blocked.

Locked Mode
:   A Freedom setting that stops you from ending a running session. Listed as a Premium feature.

## :lucide-nfc: Hardware and codes

NFC
:   Near-field communication. A tag you tap with your phone, with no battery needed.

NTAG213
:   A common low-cost NFC tag chip. Foqos lists it as compatible.

## :lucide-network: Network

VPN
:   Routes traffic through another server. It can bypass some blockers, and some blockers need it turned off.

DNS
:   Domain Name System. Translates site names to addresses. DNS-based filters work at this layer.

DoH
:   DNS over HTTPS. Encrypts lookups, which can make browser-level blocks unreliable. SelfControl's maintainers note this for Firefox.

## :lucide-users: People

Accountability partner
:   A trusted person who receives reports or holds the passcode. See [Accountability partners](accountability.md).

MDM
:   Mobile device management. Organization-level device control, usually for work or school.

GPL
:   GNU General Public License. [SelfControl](../mac/selfcontrol.md) is released under it.
