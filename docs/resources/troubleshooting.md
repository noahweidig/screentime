# Troubleshooting

## Limits stopped working

??? question "A blocked app opens anyway"

    Check that the block is active for the current time, the app is on the list (some have web versions), and the device has not changed accounts or time zone.

??? question "I forgot the Screen Time passcode"

    Contact your passcode holder first. On Apple devices, recovery usually needs the Apple Account used at setup, so keep that information with your trusted person.

??? question "A limit blocks something essential"

    Allow-list essential calls, maps, and work tools, then retest. Agree on an exception process before you need one.

??? question "I keep bypassing my limits"

    Move the passcode out of reach, shorten the exception window, and add a person. See [Basics](../basics.md).

??? question "The tool stopped after an OS update"

    Reopen the app, re-grant permissions, and confirm the block still runs. Test after every major update.

## Test routine

- [x] Trigger the block on purpose.
- [x] Request an exception.
- [x] Confirm essential apps still work.
- [x] Repeat after updates.

!!! info "Still stuck?"
