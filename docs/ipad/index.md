# iPad solutions

An iPad can be a focused creative or learning device—or a larger, more comfortable distraction. Start with Screen Time, then choose a layer that matches who uses the tablet and when.

## iPad product guide

| Product | What it adds | Good fit when… |
| --- | --- | --- |
| [Foqos](foqos.md) | Structured limits and a support-person workflow | You want stronger guardrails around iPad use |
| [Freedom](freedom.md) | Scheduled blocks for apps and sites | You need protected work or study blocks |
| [Covenant Eyes](covenant-eyes.md) | Accountability and filtering options | You want shared visibility and support |

## First steps

Set up a separate Screen Time passcode, restrict the apps that pull attention, and decide where the iPad sleeps at night. For a child or shared device, review the configuration together with the responsible adult.
