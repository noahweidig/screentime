# :lucide-scan-face: Foqos

!!! abstract "Role"

    create stronger guardrails around an Apple device with a support-person workflow.

Foqos can be a fit when Screen Time alone is too easy to change. Review its current device compatibility, plan options, and setup directions before relying on it for a household or a high-stakes goal.

[Visit Foqos :lucide-external-link:](https://foqos.app){ .md-button .md-button--primary target="_blank" rel="noopener" }

## :lucide-layout-list: At a glance

| | |
| --- | --- |
| :lucide-smartphone: **Platforms** | iPhone only. The site does not list a minimum iOS version. |
| :lucide-wallet: **Cost** | Free and open source. No subscription, ads, account or in-app purchases. Optional donations. |
| :lucide-nfc: **Unlock methods** | Manual start, NFC tag, QR code or timer. |
| :lucide-shield: **Privacy** | No account or tracking. Data stays on the iPhone. |

## :lucide-settings: How it works

- You build a profile, pick the apps and websites to block, then start it.
- Blocking uses Apple Screen Time.
- An NFC tag or QR code can start and end a session. Keep it somewhere away from your phone.
- Standard low-cost NFC tags such as NTAG213 work. QR codes are an option if you skip NFC.
- Smart breaks pause blocking without ending the whole session.

## :lucide-triangle-alert: Good to know

- The site says Foqos is made for iPhone and does not support Android.
- It does not say what happens if you lose the tag or code. Plan a backup before you rely on it.
- Its ratings and press quotes are promotional.
- The site links a separate Foqos for Mac page but gives no details here. Check it before assuming Mac support.
- For Android, the site points to independent apps (Switchly and Lock) that are not affiliated with Foqos.

## :lucide-clipboard-check: Before you begin

1. Agree on the purpose of the limits with the person who will provide support.
2. List the apps and settings that need protection.
3. Set aside time to test both normal use and a requested exception.
4. Keep the supporting person's contact and recovery process available offline.

## :lucide-thumbs-up: Use it well

A tool is strongest when it supports a clear agreement: what is restricted, when it is restricted, and how changes are requested. Revisit the agreement after the first week.
