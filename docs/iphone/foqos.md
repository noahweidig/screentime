# Foqos

**Role:** create stronger guardrails around an Apple device with a support-person workflow.

Foqos can be a fit when Screen Time alone is too easy to change. Review its current device compatibility, plan options, and setup directions before relying on it for a household or a high-stakes goal.

## Before you begin

1. Agree on the purpose of the limits with the person who will provide support.
2. List the apps and settings that need protection.
3. Set aside time to test both normal use and a requested exception.
4. Keep the supporting person's contact and recovery process available offline.

## Use it well

A tool is strongest when it supports a clear agreement: what is restricted, when it is restricted, and how changes are requested. Revisit the agreement after the first week.
