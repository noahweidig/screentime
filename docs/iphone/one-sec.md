# one sec on iPhone

!!! abstract "Role"

    add a pause before you open a distracting app.

one sec interrupts you when you open a chosen app and shows a short pause, such as a breathing exercise, before you can continue. On iPhone it is set up through Apple's Shortcuts app. The essential features are free; check the App Store listing for current Premium pricing.

[Visit one sec :lucide-external-link:](https://one-sec.app){ .md-button .md-button--primary target="_blank" rel="noopener" }

## Suggested setup

1. Pick one or two apps you open on reflex.
2. Follow the in-app steps to create the Shortcuts automations.
3. Set a pause length you will tolerate, then lengthen it later.
4. Check after a week whether you still open the app as often.

A pause adds friction but does not block. Combine it with Screen Time limits when you need a firm stop.
