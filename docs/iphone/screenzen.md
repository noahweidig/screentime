# :lucide-scan-eye: ScreenZen on iPhone

!!! abstract "Role"

    add friction and limits to distracting apps, free.

ScreenZen is a free, donation-supported app. It can add a delay before an app opens, with a wait that grows each time you open it, and it supports app goals, schedules and stricter blocks. It is also offered on Android; check Google Play for that version.

[Visit ScreenZen on the App Store :lucide-external-link:](https://apps.apple.com/us/app/screenzen-screen-time-control/id1541027222){ .md-button .md-button--primary target="_blank" rel="noopener" }

## :lucide-settings: How it works

- An opening delay before an app opens, which can grow each time you open it.
- Scroll interruptions and short check-ins.
- App goals with an optional block at the limit.
- Schedules by day of week and time of day.
- A pre-open prompt such as "Is this important?"
- Strict blocks by time range or number of opens.
- Breathing and activities while you wait.
- Minimal mode for Instagram, YouTube, TikTok and Reddit without Reels, Shorts or endless feeds.
- A daily screen-time goal and widgets.
- Streaks and a Halo feature that unlocks apps only in a chosen location.

## :lucide-triangle-alert: Good to know

- Basic pauses can be dismissed. Use strict blocks and the settings lock if you need a limit you cannot undo on impulse.
- The App Store privacy label lists usage data and diagnostics for analytics, and says the app contains advertising.
- One reviewer found website selection hard because the app shows a limited list.
- The listing does not say which features the tips unlock.

## :lucide-list-checks: Suggested setup

1. Choose the apps that eat the most time.
2. Start with a short delay before opening them.
3. Add a schedule for the hours you most want protected.
4. Review your numbers after a week and adjust.

Basic pauses can be dismissed. Use its stricter options, or a tool with an outside support person, if you need a limit you cannot undo on impulse.
