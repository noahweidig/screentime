# :lucide-waves: Ripple on Android

!!! abstract "Role"

    block chosen apps on a schedule and make the rules hard to undo on the same phone.

Ripple is a small app for adults who want to stop late night scrolling and for parents setting up a child's phone. Rule changes wait through a cooldown, and an unlock code can be held by a parent or a friend.

[Visit Ripple :lucide-external-link:](https://ripplefocus.github.io/){ .md-button .md-button--primary target="_blank" rel="noopener" }

## :lucide-settings: How it works

- You pick apps and time windows. Outside those windows the apps are blocked.
- It can block parts of an app, such as WeChat Channels and Moments, YouTube Shorts or Instagram Reels, while the rest of the app keeps working.
- Changing or removing a rule starts a 15 minute cooldown, or needs an unlock code that someone else holds.
- Timing uses the phone's uptime clock, so changing the system date or time does not end a block.
- Uninstall protection can be turned on from the phone itself, without connecting a computer.

## :lucide-triangle-alert: Good to know

- It relies on Accessibility and device administration permissions. Some phone makers stop background apps, so allow Ripple to run in the background.
- The app is new and maintained by a small team. Check the website for the current version.

## :lucide-list-checks: Suggested setup

1. Install the APK and grant the permissions the app asks for.
2. Add one or two apps you open on reflex and set a schedule.
3. Give the unlock code to a parent, partner or friend.
4. Turn on uninstall protection once the rules feel right.
