# Freedom on Android

**Role:** schedule focused time by blocking selected distractions.

Freedom can help protect a recurring work, study, rest, or family block. Use it alongside—not instead of—clear notification settings and a device settings and a reliable lock screen that is not easy to override.

## Suggested setup

1. Start with the two or three apps or sites that most often interrupt you.
2. Create one short recurring block at a realistic time.
3. Test that your essential calls, maps, and work tools still function as intended.
4. Expand only after the first block becomes routine.

See the [Windows guide](../windows/freedom.md) if you want your computer focus sessions to match.
