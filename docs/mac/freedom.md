# Freedom on Mac

!!! abstract "Role"

    schedule focused time by blocking selected distractions.

Freedom can help protect a recurring work, study, rest, or family block. Use it alongside—not instead of—clear notification settings and a macOS user account and focus settings that are not easy to override.

[Visit Freedom :lucide-external-link:](https://freedom.to){ .md-button .md-button--primary target="_blank" rel="noopener" }

## Suggested setup

1. Start with the two or three apps or sites that most often interrupt you.
2. Create one short recurring block at a realistic time.
3. Test that your essential calls, maps, and work tools still function as intended.
4. Expand only after the first block becomes routine.

Use the same short list of distractions across your devices when you want a consistent focus routine.
