*[Screen Time]: Apple's built-in tool for app limits, Downtime and content restrictions on iPhone, iPad and Mac.
*[Digital Wellbeing]: Google's built-in Android tool for app timers, Focus mode and Bedtime mode.
*[Downtime]: A Screen Time schedule that allows only apps you choose and phone calls.
*[App Limits]: Screen Time daily time limits for app categories or individual apps.
*[NFC]: Near-field communication. A tag you tap with your phone, with no battery needed.
*[NTAG213]: A common low-cost NFC tag chip. Foqos lists it as compatible.
*[QR code]: A scannable square barcode. Foqos can use one to start or end a session.
*[VPN]: Virtual private network. Routes traffic through another server and can bypass some blockers.
*[DNS]: Domain Name System. Translates site names to addresses. DNS-based filters work at this layer.
*[DoH]: DNS over HTTPS. Encrypts DNS lookups, which can bypass some website blockers.
*[GPL]: GNU General Public License. A free software license that requires source code to stay open.
*[Allowlist]: A list of the only sites or apps permitted. Everything else is blocked.
*[Blocklist]: A list of sites or apps that are blocked. Everything else is allowed.
*[Locked Mode]: A Freedom setting that stops you from ending a running session.
*[Accountability partner]: A trusted person who receives reports or holds the passcode.
*[MDM]: Mobile device management. Organization-level control of devices, usually for work or school.
*[Family Sharing]: Apple's feature for sharing purchases and parental controls within a household.
*[Family Link]: Google's parental control app for supervising a child's Android device.
